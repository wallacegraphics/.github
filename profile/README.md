# Wallace Graphics · Engineering

Commercial print + tech. We build systems that move jobs from **order → production → shipment → invoice** with zero drama.

- **What we do**: Wide-format + direct mail + fulfillment at scale. Our software automates intake, validation, imposition, shipping, and reporting.

## Core Technologies
- **Backend (Node):** NestJS, TypeScript, Node.js
- **Backend (.NET):** .NET 8, ASP.NET Core
- **Legacy (.NET):** .NET Framework, ASP.NET
- **Frontend (Typescript):** React, Next.js
- **Frontend (ASP.NET):** Razor Pages
- **Databases:** PostgreSQL, Microsoft SQL Server (MSSQL)
- **Containers/Infra:** Docker, AWS, on-prem integrations (PACE, SiteFlow, UPS/FedEx/USPS)

## How to contribute
1. Create a feature branch: `feat/<scope>-<short-desc>`.
2. Write tests. Keep PRs small. Add docs where it helps the next person.
3. Submit PR → passing checks → review from `@wallacegraphics/devops`.

See **[CONTRIBUTING.md](../CONTRIBUTING.md)** for details.

## Security & data
- **No secrets in code.** Use GitHub Secrets or AWS Parameter Store.
- Customer data is sensitive. Follow our **[SECURITY.md](../SECURITY.md)**.
- Report vulnerabilities via **security advisories** (private).
