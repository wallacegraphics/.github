# Wallace Graphics · Engineering

Commercial print + tech. We build systems that move jobs from **order → production → shipment → invoice** with zero drama.

- **What we do**: Wide-format + direct mail + fulfillment at scale. Our software automates intake, validation, imposition, shipping, and reporting.
- **Core stack**: NestJS/Node, React/Next.js, PostgreSQL, Docker, AWS + on-prem (PACE, SiteFlow, UPS/FedEx/USPS).
- **Standards**: TypeScript, ESLint+Prettier, Conventional Commits, CI for tests/lint/build.

## How to contribute
1. Open an issue using the right template.
2. Create a feature branch: `feat/<scope>-<short-desc>`.
3. Write tests. Keep PRs small. Add docs where it helps the next person.
4. Submit PR → passing checks → review from `@wallacegraphics/devops`.

See **[CONTRIBUTING.md](../CONTRIBUTING.md)** for details.

## Security & data
- **No secrets in code.** Use GitHub Secrets or AWS Parameter Store.
- Customer data is sensitive. Follow our **[SECURITY.md](../SECURITY.md)**.
- Report vulnerabilities via **security advisories** (private).
